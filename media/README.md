# Common Ground demonstration video

`common-ground-demo.mp4` is the 100-second, 1920×1080 narrated demo. It contains the provided narration and an embedded English closed-caption track; `common-ground-demo.en.srt` is also available separately.

The video uses actual CDP screen-capture frames from the running prototype, preserving each scene's action order. Holds were extended to match the explanation. One brief blank scroll frame was omitted. Editorial lower thirds summarize observed behavior. No screen state, success notification or interaction result was generated. The budget preset's reset of the protected favorite is explicitly disclosed: **“Budget scenario: original minimums.”**

`edit-manifest.json` records source frames/timestamps, output timing, captions and narration hash. `edit.py` reproduces the edit from the original `raw/scene1`–`scene7` captures and narration. It requires Python/Pillow, ffmpeg and the local Arial font. Raw captures and renders remain local and ignored by Git; the publishing owner handles public upload.

The demo is a working design prototype using illustrative costs and scores. The video makes no field-impact claim. No public submission or acceptance is established by producing this file.
